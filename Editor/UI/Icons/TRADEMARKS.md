| File | Provenance / official reference |
| --- | --- |
| `codex.png` | Restored original icon sourced from the installed OpenAI app. [OpenAI brand guidelines](https://openai.com/brand/) |
| `claude-code.png` | Restored original icon sourced from [Claude Code documentation](https://code.claude.com/docs/en/overview). |

Icons keep their original pixels and proportions. Unity caps imported texture size at 128 pixels with mipmaps disabled. These source references document provenance, not a claim of a separate permission grant.
