# Client illustrations

`client-icons.png` is an original set of neutral pictograms generated with the built-in image generation tool for LittleBrush Unity MCP. It is included under this repository's MIT license to the extent applicable. It contains no official client logos.

Client names identify compatible products and belong to their respective owners. These illustrations do not imply endorsement or affiliation.

The four cells depict a code book, terminal, connection and pen. They are sampled from one shared texture; mipmaps are disabled and the import size is capped at 512 pixels.
