# Client icon sheet

Generated using the built-in image generation tool. Original neutral pictograms replace
third-party client logos. Runtime UI samples four square regions from one texture.

Prompt:

Create ONE sprite sheet containing exactly FOUR extremely simple flat UI pictograms arranged in one horizontal row of four equal square cells. Wide 4:1 canvas. All icons same visual size, centered with generous identical padding. Cell 1: open book with a simple code chevron. Cell 2: terminal rectangle with >_ prompt. Cell 3: two simple connected links. Cell 4: simple fountain pen nib. These are original neutral client selector illustrations, NOT any company's official logos. Style: bold minimal flat glyphs, consistent thick strokes, maximum two solid colors per glyph: warm cream #F7E3C4 and amber #FFAD46. Entire background uniform solid charcoal #242424. Absolutely NO gradients, shading, bevels, metallic surfaces, fine details, textures, checkerboard, shadows, borders around cells, text labels or decorative flourishes. Each icon must be legible at 24x24 pixels. Think a tiny coherent toolbar icon set, not illustrations or app store icons. All four must be present on this ONE image.

The generated canvas is 1774 × 887; the four icons occupy its central horizontal band.
