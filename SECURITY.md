# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private [Report a vulnerability](https://github.com/actionk/LittleBrush.UnityMCP/security/advisories/new) form and include reproduction steps, affected versions, impact, and any suggested mitigation.

## Maintainer setup

GitHub private vulnerability reporting is available for public repositories. Enable it
when making this repository public, then verify the reporting link above. See
[GitHub's configuration guide](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository).
